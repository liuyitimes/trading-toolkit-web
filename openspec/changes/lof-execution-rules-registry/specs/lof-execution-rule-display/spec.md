## ADDED Requirements

### Requirement: LOF 场内规则列表展示

Web 应用 MUST 在 LOF 桌面列表展示服务端返回的场内申购确认时效、场内赎回到账时效和最低申/赎。最低申/赎 MUST 使用独立稳定宽度列，申购与赎回分别占一行，并保留服务端给出的元或份单位。

#### Scenario: 规则完整且单位不同

- **GIVEN** 服务端返回场内申购 T+n、场内赎回 T+n、申购最低金额和赎回最低份额
- **WHEN** 用户查看桌面 LOF 列表
- **THEN** 时效列显示申购和赎回两行
- **AND** 最低申/赎列显示原始的元和份单位而不进行换算

#### Scenario: 静态规则存在但状态待核验

- **GIVEN** 服务端返回有效静态规则且申购状态为待核验
- **WHEN** 用户查看列表或移动卡片
- **THEN** 页面显示静态规则和待核验状态
- **AND** 页面不把该基金显示为可执行套利

### Requirement: LOF 场内规则详情证据

Web 应用 MUST 在 LOF 详情页展示最低申购和最低赎回及其字段级证据；缺失规则 MUST 显示 `--`。时效值和最低门槛均由服务端提供，客户端不得推导或补值。

#### Scenario: 字段未获取

- **GIVEN** 服务端没有返回某一最低申赎或时效字段
- **WHEN** 用户查看列表、移动卡片或详情页
- **THEN** 对应位置显示 `--`
- **AND** 页面其余字段继续正常显示
