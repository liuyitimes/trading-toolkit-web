# LOF 场内规则展示

## 背景

LOF 页面已有时效展示容器，但当前服务端未提供可审计规则，且列表未显示最低申/赎。用户需要直接比较场内申购确认、赎回到账和最小交易门槛，同时不把缺失或状态待核验误表示为可执行套利。

## 变更内容

- 消费配套服务端 `lof-execution-rules-registry` 的场内规则字段。
- 桌面列表增加“最低申/赎”独立列，申购与赎回分别两行展示。
- 移动卡片增加紧凑场内规则信息块；详情保留完整证据链接与适用信息。

## 能力

### 新增能力

- `lof-execution-rule-display`: LOF 场内时效和最低申/赎的列表、移动端及详情展示。

### 修改能力

- `lof-funds`: 规范化可选场内规则接口字段并保持缺失兼容。

## 影响

- 影响 `src/stores/lof.js`、`src/utils/lofSettlementTiming.js`、`src/views/LOF.vue` 和 `src/views/LofDetail.vue`。
- 依赖配套服务端变更，但缺少新字段的旧响应仍可渲染。
- 回滚时移除新增列与规则块，现有列表数据不受影响。
