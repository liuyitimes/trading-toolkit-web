# 手动刷新行情数据

## 为什么

金融行情和研究数据具有缓存与上游延迟，用户需要知道当前页面数据何时加载，并在需要时主动触发一次强制回源。现有顶部只展示更新时间，没有统一的刷新入口，且重复请求可能仍命中服务端缓存。

## 变更内容

- 在共享顶部栏提供“刷新当前数据”按钮，并显示加载态、防止重复点击和成功/失败反馈。
- 按当前路由注册页面刷新动作，覆盖市场概览、列表页和详情页。
- 各页面刷新动作向服务端读取端点传递 `refresh=true`，保留现有数据和用户假设，不改变筛选、分页或详情上下文。
- 让首页综合市场概览端点支持 `refresh=true`，以便首页刷新真正触发各组成数据的强制刷新。
- 保留现有更新时间展示；刷新请求成功后更新客户端更新时间。

## 能力

### 新增能力

- `manual-refresh`: 用户从共享布局刷新当前页面数据。

### 修改能力

- `web-application`: 增加共享布局的当前页面刷新行为。

## 影响

- Web：`Layout.vue`、`app.js`、首页、行情列表和详情视图、各业务 API 封装与 store。
- Service：综合市场概览路由读取 `refresh=true` 并将强制刷新传递给组成数据端点；对应变更名为 `manual-refresh-data`。
- 不新增依赖、不新增浏览器持久化，也不改变 HTTP 响应信封格式。

## 回滚

移除共享刷新按钮、页面刷新注册和 `refresh` 参数传递即可恢复原有加载行为；服务端恢复综合概览的默认缓存读取即可回滚服务侧变更。
