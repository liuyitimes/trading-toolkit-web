# 提案：准确展示公告驱动的首日可交易量

## 背景

服务端在配售公告缺失时会返回未知状态。Web 当前部分兼容逻辑会把未知配售率当作 0，用户无法区分真实的 0% 与尚未取得数据。

## 目标

保持 API 的 `null` 语义，在配售列表、详情和公式提示中将未知股东配售率、首日可交易量显示为 `--`，并保留公告来源状态。

## 非目标

- 不在客户端推断股东配售量。
- 不改变已确认的预期上市溢价、收益或排序口径。

## 配套变更

服务端仓库存在同名 `placement-tradable-amount-announcement` 变更，负责数据获取和 API 字段。
