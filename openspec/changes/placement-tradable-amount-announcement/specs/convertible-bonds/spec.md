## ADDED Requirements

### Requirement: 未知配售数据的展示

Web MUST 将服务端 `shareholder_ratio`、`shareholder_amount` 或 `tradable_amount` 的 `null` 显示为 `--`，不得转换为 0 或发行规模。

#### 场景：公告值存在

- **假定**：候选标的返回公告解析的原股东配售率和首日可交易量。
- **当**：用户查看配债列表或详情。
- **则**：页面显示真实数值，并保留公告来源状态。

#### 场景：公告缺失

- **假定**：候选标的的配售字段为 `null`。
- **当**：用户查看配债列表、详情或公式提示。
- **则**：相关字段显示 `--`。
- **并且**：公式提示明确说明等待公告核验，不展示伪造计算结果。
