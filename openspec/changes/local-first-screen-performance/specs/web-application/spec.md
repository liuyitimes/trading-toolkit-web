## ADDED Requirements

### Requirement: 本机首屏 API 路由

浏览器在本机主机名访问 Web 时，必须通过相对 `/api` 地址使用本地 Vite 代理，不得使用生产远端 API 地址或保存在浏览器中的远端覆盖地址。

#### Scenario: 本机预览打开 LOF 或可转债页面

- **假定**：页面主机名为 `localhost` 或 `127.0.0.1`。
- **当**：页面发起 API 请求。
- **则**：请求目标为相对 `/api` 路径。
- **并且**：Vite 将请求转发到本机 Ubuntu 后端。

### Requirement: 首屏不被附属指标阻塞

LOF 和可转债页面必须在主列表或首要数据可用后结束全页加载；摘要、信号、市场概览和新债等附属指标可在随后独立更新。

#### Scenario: LOF 摘要接口变慢

- **假定**：LOF 列表正常返回，摘要接口响应超过 2 秒。
- **当**：用户打开 LOF 页面。
- **则**：列表到达后 1 秒内结束全页加载。
- **并且**：摘要返回后更新市场概览。

#### Scenario: 可转债信号接口变慢

- **假定**：可转债信号接口响应超过 2 秒。
- **当**：用户打开可转债页面。
- **则**：页面在 1 秒内结束全页加载。
- **并且**：信号返回后独立更新策略区域。
