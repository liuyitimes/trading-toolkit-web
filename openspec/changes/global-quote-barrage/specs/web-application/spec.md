## ADDED Requirements

### Requirement: 全站名言弹幕

Web 应用 SHALL 在桌面端的所有受支持路由中，于共享页头和可滚动内容区之间显示名言弹幕。弹幕必须占用独立布局空间，不得遮挡或拦截内容区的按钮、输入框、表格操作、弹窗或浮动工具的操作。

#### Scenario: 用户浏览任意桌面端路由

- GIVEN 用户在宽度大于 768px 的受支持 Web 路由中
- WHEN 共享布局完成渲染
- THEN 页头下方、内容区上方显示名言弹幕
- AND 普通弹幕区域的指针操作穿透至下方内容。

#### Scenario: 用户在窄屏或减少动态效果模式下浏览

- GIVEN 视口宽度不大于 768px，或系统声明 `prefers-reduced-motion: reduce`
- WHEN 共享布局完成渲染
- THEN 不显示名言弹幕及其关闭按钮。

### Requirement: 随机名言批次

名言弹幕 SHALL 在首次进入页面及每次路由切换时，从当前名言列表中随机选择 2 至 3 条不同名言组成单行播放批次；但名言管理变更后，当前批次在完成前不得被路由切换替换。当列表不足三条时，必须选择全部名言。批次在 40 秒内从右向左匀速连续播放，完成后等待 4 秒再播放下一批。

#### Scenario: 名言列表包含至少三条名言

- GIVEN 当前名言列表包含至少三条名言
- WHEN 用户首次进入页面或切换路由
- THEN 弹幕随机显示 2 或 3 条互不重复的名言
- AND 同一批名言在单一轨道中依次经过。

#### Scenario: 名言列表不足三条

- GIVEN 当前名言列表包含一条或两条名言
- WHEN 弹幕生成新批次
- THEN 该批次包含列表中的全部名言
- AND 不为补足数量重复同一名言。

#### Scenario: 名言管理修改列表

- GIVEN 弹幕正在播放一个批次
- WHEN 用户添加、编辑、删除名言或恢复默认名言
- THEN 当前批次保持不变直至播放完成
- AND 下一批基于更新后的名言列表生成。

#### Scenario: 名言管理修改后用户切换路由

- GIVEN 名言管理修改已更新名言列表且当前批次尚未完成
- WHEN 用户切换至另一受支持路由
- THEN 当前批次保持不变直至播放完成
- AND 下一批基于更新后的名言列表生成。

### Requirement: 临时关闭名言弹幕

名言弹幕 SHALL 提供带中文可访问名称的图标关闭按钮。关闭状态必须在当前应用运行期内跨路由保持，但页面刷新后恢复为显示状态，且不得修改名言列表。

#### Scenario: 用户关闭弹幕后切换路由

- GIVEN 用户在桌面端已关闭名言弹幕
- WHEN 用户切换至另一受支持路由
- THEN 弹幕保持隐藏
- AND 名言管理中的名言数据不变。

#### Scenario: 用户刷新页面

- GIVEN 用户在当前应用运行期内关闭过名言弹幕
- WHEN 用户刷新页面
- THEN 弹幕恢复显示（除非当前视口为窄屏或系统减少动态效果）。
