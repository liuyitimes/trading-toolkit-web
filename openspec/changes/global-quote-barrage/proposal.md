# 全站名言弹幕

## 背景与目标

现有首页名言组件会按固定顺序循环全部名言，既不在其他路由显示，也无法满足随机展示少量名言的阅读节奏。将其改为桌面端共享布局中的非阻断式名言弹幕，让用户管理的名言在浏览各功能页时随机飘过。

## 范围

- 在桌面端所有受支持路由的内容区顶部展示名言弹幕。
- 每个初始页面和路由切换随机选择 2 至 3 条互不重复名言，并在单行中依次播放。
- 支持减少动态效果、窄屏隐藏和本次应用运行期关闭。
- 名言管理的变更在当前批次结束后的下一批生效。

## 非目标

- 不修改名言管理页的 CRUD 字段与本地持久化格式。
- 不提供服务端同步、名言分类或跨设备偏好。
- 不在移动端展示静态替代文本。

## 回退

移除共享布局中的弹幕组件即可恢复为无全站弹幕的展示；名言管理数据不受影响。
