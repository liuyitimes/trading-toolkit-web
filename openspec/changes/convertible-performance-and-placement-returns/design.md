## 目标

让用户在同一个可转债工作区里同时观察待配债机会的预期总收益，以及今年上市新债的真实上市表现。

## 决策

1. 新增主 Tab `new_listed`，显示文案为“今年新债”，并接入 `GET /api/v1/convertible/new-listed`。
2. 新债表现列表使用服务端提供的数值字段，前端只格式化百分比和颜色，不在浏览器里推断交易日。
3. 配债详情新增“参与后收益”展示区，按当前全局预期上市溢价率动态重算转债预期收益与总收益，但历史价格只使用服务端返回的固定值。
4. `recordPrice` 继续兼容旧响应，但新展示优先使用 `registrationClosePrice`，避免把当前价显示成登记日事实。
5. 今年新债“发行以来”以服务端返回的面值 100 元基准涨幅展示；不展示本月字段。“发行规模”仅表示东财发行总额，不表示实时流通规模或扣除锁定份额后的余额。

## 非目标

- 不新增图表。
- 不做历史价格本地缓存。
- 不改变收藏、导出和既有信号筛选逻辑。
