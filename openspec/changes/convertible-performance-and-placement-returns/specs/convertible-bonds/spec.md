## ADDED Requirements

### Requirement: 配债参与后总收益展示

Web MUST 在配债详情中展示服务端提供的股权登记日收盘价、登记日后收尾价，并基于当前预期上市溢价率计算参与配债后总收益，明确区分正股盈亏与转债预期收益。

#### Scenario: 候选标的有完整收益事实

- **假定**：待配债候选标的包含登记日收盘价、后续收盘价和总收益字段。
- **当**：用户打开该候选标的详情。
- **则**：详情展示登记日收盘价、收尾价、正股盈亏、转债预期收益、总收益和总收益率。
- **并且**：总收益随当前预期上市溢价率假设重新计算。

#### Scenario: 历史价格不可用

- **假定**：服务端未返回可验证历史收盘价。
- **当**：用户查看详情。
- **则**：相关收益字段显示 `--` 或“暂无”。
- **并且**：不得把当前正股价展示为登记日收盘价。

### Requirement: 今年上市新债列表

Web MUST 提供今年上市新债列表，用于展示发行以来涨幅、上市前三日涨幅、发行规模与换手率，并可进入单只转债详情。

#### Scenario: 用户打开今年新债 Tab

- **假定**：服务端返回今年上市新债表现列表。
- **当**：用户切换到“今年新债”Tab。
- **则**：页面显示转债、正股、上市日、最新价、发行以来涨幅、上市前三日涨幅、发行规模和换手率。
- **并且**：发行规模须明确为东财发行总额，不能表示为扣除锁定份额后的实时流通规模。
- **并且**：上市未满三个交易日时，前三日字段显示已完成的第 1 / 2 / 3 个交易日阶段。
- **并且**：不可用字段显示 `--`。

#### Scenario: 用户进入新债详情

- **假定**：服务端返回单只转债详情。
- **当**：用户点击新债行或卡片。
- **则**：跳转到转债详情页并渲染实际内容。
- **并且**：详情加载失败或返回空时，页面显示失败提示与重试按钮，不得空白。
