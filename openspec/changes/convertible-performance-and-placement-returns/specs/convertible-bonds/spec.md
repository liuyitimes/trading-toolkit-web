## ADDED Requirements

### Requirement: 配债参与后总收益展示

Web MUST 在配债详情中展示服务端提供的股权登记日收盘价、登记日后收尾价，并基于当前预期上市溢价率计算参与配债后总收益，明确区分正股盈亏与转债预期收益。

#### Scenario: 候选标的有完整收益事实

- **假定**：待配债候选标的包含登记日收盘价、后续收盘价和总收益字段。
- **当**：用户打开该候选标的详情。
- **则**：详情展示登记日收盘价、收尾价、正股盈亏、转债预期收益、总收益和总收益率。
- **并且**：总收益随当前预期上市溢价率假设重新计算。

#### Scenario: 历史价格不可用

- **假定**：服务端未返回可验证历史收盘价。
- **当**：用户查看详情。
- **则**：相关收益字段显示 `--` 或“暂无”。
- **并且**：不得把当前正股价展示为登记日收盘价。

### Requirement: 今年上市新债列表

Web MUST 提供今年上市新债列表，用于展示上市以来、本月和上市前三个交易日的涨幅。

#### Scenario: 用户打开今年新债 Tab

- **假定**：服务端返回今年上市新债表现列表。
- **当**：用户切换到“今年新债”Tab。
- **则**：页面显示转债、正股、上市日、最新价、上市以来涨幅、本月涨幅和上市前三日涨幅。
- **并且**：涨幅为正、负和不可用时有清晰的视觉区分。

#### Scenario: 新债上市未满三个交易日

- **假定**：服务端只返回阶段性三日涨幅或返回不可用。
- **当**：列表渲染该标的。
- **则**：可用阶段涨幅正常显示。
- **并且**：不可用字段显示 `--`。
