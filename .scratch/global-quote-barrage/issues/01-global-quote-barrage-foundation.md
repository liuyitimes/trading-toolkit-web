# 01 — 全站随机名言弹幕基础体验

**交付内容：** 在桌面端所有受支持路由中提供位于页头与内容区之间的单行名言弹幕。它从用户维护的名言列表中随机抽取 2 至 3 条互不重复名言，在单一轨道中按 40 秒播放、4 秒空档的节奏展示；窄屏和减少动态效果时隐藏。名言管理与全站展示共享响应式名言数据，现有名言 CRUD 继续可用。

**依赖：** 无，可立即开始。

**Status:** resolved

- [x] 桌面端首次进入和切换任意受支持路由时，均显示由 2 至 3 条不重复名言组成的单行批次；列表不足三条时仅显示全部已有名言且不重复。
- [x] 弹幕位于共享页头与可滚动内容区之间并占用独立空间，窄屏与系统减少动态效果时不显示。
- [x] 名言管理的添加、编辑、删除和恢复默认保持既有用户可见行为，并可供全站弹幕读取最新列表。
- [x] 浏览器级测试覆盖桌面端展示、路由切换、名言数量边界、窄屏、减少动态效果和无页面错误。
