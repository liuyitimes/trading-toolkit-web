# 02 — 名言弹幕的非干扰控制与延迟更新

**交付内容：** 让全站名言弹幕在不干扰研究操作的前提下可临时关闭，并在名言管理内容变化时保持阅读连续性。普通弹幕区域点击穿透；用户可通过带中文可访问名称的图标关闭按钮，在当前应用运行期内跨路由隐藏弹幕。当前批次完整结束后，下一批才使用更新后的名言列表。

**依赖：** 01 — 全站随机名言弹幕基础体验。

**Status:** resolved

- [x] 普通弹幕区域不截获下方内容的点击；关闭图标是唯一可交互区域，且具有中文可访问名称。
- [x] 用户关闭弹幕后跨路由保持隐藏；刷新页面后恢复默认显示，且关闭操作不修改名言列表。
- [x] 添加、编辑、删除名言或恢复默认时，正在播放的批次不跳变，下一批使用更新后的列表。
- [x] 浏览器级测试覆盖点击穿透、关闭状态跨路由、刷新恢复、关闭控件可访问名称，以及延迟应用名言更新，且无页面错误。
