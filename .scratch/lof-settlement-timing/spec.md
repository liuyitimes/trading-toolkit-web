# LOF 交割时效展示

Status: ready-for-agent

权威的 Web 变更文档位于 `openspec/changes/lof-settlement-timing/`，并对应 `trading-toolkit-service` 的同名变更。

## 用户目标

作为 LOF 套利研究者，我希望在列表、移动卡片和详情中看到每只基金的申购确认与赎回到账 `T+n`，以便把结算窗口风险纳入判断，而不是根据交易所或经验猜测规则。

## 已确认决策

- 申购确认与赎回到账是独立字段，按基金逐只展示。
- 值只来自当前有效的基金管理人或发行人材料，保留原有工作日或交易日口径。
- 列表和移动卡片显示紧凑的 `申 {T+n} / 赎 {T+n}`；详情显示来源、有效日期、核验时间和状态。
- 部分缺失时显示已核验侧与另一侧的 `暂缺`，并标记执行路径未完整核验，不能称为可执行套利。
- 旧的按交易所推断赎回时效的逻辑被彻底移除。
- Service 提供可选字段；在其尚未上线时 Web 稳定降级为 `暂缺`。

## 非目标

- 客户端推算 T+n、用户实际成交日期或收益。
- 修改申购限额、转托管和套利收益计算。
