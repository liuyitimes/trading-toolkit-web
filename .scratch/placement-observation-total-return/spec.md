# 配债观察标的与预期总收益

Status: ready-for-agent

本规格与 `trading-toolkit-service/.scratch/placement-observation-total-return/spec.md` 配套。Web 消费服务提供的观察状态和历史价格事实，并使用用户本地的预期上市溢价率计算派生值。

## Problem Statement

配债工作区当前隐藏登记日已过的标的，无法完整观察近期发行进程；其排序未区分临近登记、登记日未知和已过期。详情页也没有将正股登记后价格变化与现有预计上市收益率组合成清晰、可审计的税费前预期总收益。

## Solution

配债视图将服务提供的未上市末段观察标的按三组展示：未来或当日登记按日期升序、登记日未知居中、已过期按登记日降序。已过期记录保留且显式标记，不可伪装为当前可参与机会。

详情页以一手配债为单位显示税费前预期总收益。它使用服务提供的登记日和后续首个交易日收盘价、实际整百股数，并复用现有本地持久化的预期上市溢价率；用户变更该假设时，所有派生值本地同步重算，无需请求服务。

## User Stories

1. 作为配债观察者，我希望在一个列表中看到未上市的末段审批和后续发行记录，以便跟踪近期配债。
2. 作为配债观察者，我希望今天和未来登记的标的优先显示，以便及时采取行动。
3. 作为配债观察者，我希望登记日未知的标的不被隐藏，以便继续关注待公告项目。
4. 作为配债观察者，我希望登记日已过的标的显示“已过期”，以便区分观察和当前资格。
5. 作为配债观察者，我希望最近过期的记录排在更早过期记录之前，以便快速复盘。
6. 作为配债观察者，我希望看到审批或发行进度，以便理解记录为何被纳入观察列表。
7. 作为详情用户，我希望看到一手配债的税费前预期总收益，以便比较不同观察标的。
8. 作为详情用户，我希望看到登记日收盘价、后续首个交易日收盘价和实际整百股数，以便审阅总收益的输入。
9. 作为详情用户，我希望在收益输入不可用时看到明确状态，而不是零元或当前价替代。
10. 作为使用者，我希望总收益随着工具栏的预期上市溢价率立即变化，以便比较不同情景。
11. 作为使用者，我希望总收益明确显示为税费前预期值，以便不把它当作实际收益、保证收益或个人账户结果。
12. 作为移动端用户，我希望过期状态、收益假设和详情公式在小屏幕上完整可读，以便不遗漏风险提示。
13. 作为导出用户，我希望导出内容继续保留既有配债字段和当前收益率假设，以便与页面一致。

## Implementation Decisions

- 视图不再自行移除登记日已过的观察标的；服务端提供的观察状态是唯一资格事实。
- 列表排序依次为未来或当日登记、登记日未知、已过期；未来组按日期升序，过期组按日期降序。
- 已过期标签使用风险或不可参与语义，不使用机会或推荐颜色，不暗示当前仍可获得配售资格。
- 税费前预期总收益复用现有全局、本地持久化的预期上市溢价率；不新增第二个收益率选择器。
- 详情展示一手配债口径：正股历史价差乘以实际整百股数，加上 1,000 元面值乘以活动预期上市溢价率。
- 详情必须同时展示输入日期、价格、股数、活动假设和公式说明；任一服务输入不可用时总收益显示不可用与原因。
- 全部收益相关文本必须披露为税费前预期值，不含账户费用、融资、实际获配数量或上市后的实际成交。
- 现有配债评分、预估收益、安全垫和导出继续使用相同的活动收益率假设；本变更不改变它们的既有定义。

## Testing Decisions

- 最高客户端 seam 为配债 Pinia 派生列表和详情展示，而不是组件内部的排序辅助函数。
- Store 测试覆盖三组排序、已过期标签、登记日未知保留、活动收益率切换与无网络重算。
- 详情测试覆盖完整历史输入的总收益、周末或节假日后的服务日期展示、缺失输入的不可用状态和假设披露。
- 浏览器回归覆盖桌面表格、移动卡片、详情弹窗和收益率选择器，确认标签、金额、公式和文字不重叠。
- 复用现有配债收益率假设、配债详情和导出测试；断言只验证用户可见的排序、状态和数值。

## Out of Scope

- 个人实际配债、账户成交、税费、融资利息和税后结果。
- 上市首日或之后的实际转债卖出收益。
- 新的用户账户设置或服务端收益率偏好。
- 把早期审批项目加入配债观察列表。
- 服务数据不完整时的客户端补值或当前价推断。

## Further Notes

总收益是研究和比较工具，非投资建议。它以服务端可验证的历史事实加上用户可见的本地假设构成，二者必须在详情使用点分别披露。

对应领域决策见 `docs/adr/0004-placement-observation-and-expected-total-return-display.md`。
