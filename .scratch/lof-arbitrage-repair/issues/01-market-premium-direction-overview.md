# 01 — 溢价热点方向概览

**What to build:** 用户在 LOF 市场概览中看到有经核验分类方法、加权溢价、样本量和未分类覆盖说明的溢价热点方向；没有有效数据时看到 `暂缺` 与原因。

**Blocked by:** None — can start immediately.

**Status:** resolved

- [x] Service 返回带来源、日期、分类方法、样本量和可用性状态的热点方向。
- [x] Web 渲染热点方向及其证据，且不从缺失值或零值推断方向。
- [x] 契约和浏览器验证覆盖已提供与不可用两种状态。

## Answer

`hot_direction` 现在包含状态、不可用原因、行情日期、分类来源、获取时间、加权溢价、样本量、未分类覆盖及可审查的分类基金构成。Web 仅在整组证据完整时显示方向；否则显示 `暂缺` 与原因。浏览器验证覆盖可用、缺失证据和不可用三种状态，服务端测试覆盖实际摘要响应。
